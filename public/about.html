About Wise MMDC

MO-IT149 - Web Technology Application

Project Description

This project is a web application designed for MO-IT149 - Web Technology Application course. Its primary goal is to help Filipino students compare the monthly expenses of a traditional, on-campus learning setup versus an online learning setup, like the one at MMDC.

The application provides a simple calculator where students can input their income and typical expenses for both scenarios to see a direct comparison of their remaining balance.

This tool aims to help students make more informed financial decisions about their education path.

Features

💰 Expense Calculator

Compare monthly costs between traditional and online learning with customizable expense categories.

📊 Real-time Comparison

See instant calculations and balance comparisons as you input your data.

📱 Responsive Design

Access the calculator on any device - desktop, tablet, or mobile.

✨ Interactive Features

Enhanced with JavaScript for better user experience and interactivity.

Privacy & Data Protection

🔒 Your Privacy Matters

We respect your privacy. This website is designed as an educational project and does NOT collect, store, or transmit any personal information from its users.

All calculations are performed locally in your browser. No data is sent to any server or third party. Your financial information remains private and secure on your device.

📋 Data Privacy Act of 2012 (Republic Act No. 10173)
This website is developed in compliance with the Philippine Data Privacy Act of 2012, which protects the fundamental human right to privacy while ensuring the free flow of information for innovation and growth. As this is a purely educational, client-side application, no personal data processing occurs that would require data privacy registration or user consent mechanisms.

Project Milestones

Milestone 1 - Database Integration with CRUD Operations

  • Migrated the application database to MongoDB
  • Implemented full CRUD operations (Create, Read, Update, Delete) for managing application data
  • Configured database connection using MongoDB Atlas
  • Structured collections and documents for efficient data storage and retrieval
  • Tested CRUD endpoints using API tools

Milestone 2 - Secure Web App with Authentication and File Storage

  • Google OAuth Authentication: Users can securely sign in using Google accounts
  • Role-Based Access Control (RBAC): Route protection with separate access for users and admins
  • File Upload and Retrieval: Users can upload and view files while admins can access all uploaded files
  • File Validation: File type and file size validation before upload
  • Firebase Storage Support: Cloud storage integration with fallback to local storage
  • Security Middleware: Helmet used to enforce secure HTTP headers
  • Input Validation: express-validator ensures safe and validated user inputs
  • Centralized Error Handling: A single error handler manages application and upload errors
